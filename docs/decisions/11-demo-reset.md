# 11. 데모 초기화 — 없는 기능을 근거로 삼은 상태를 끝낸다

> 이슈 #10 · PR #17 · `app/demo/`

## 왜

`CLAUDE.md`가 **"반드시 만든다"**고 선언해뒀는데 **라우트가 0건**이었다.

더 나쁜 건 저장소 여러 곳이 이 기능을 **전제로** 쓰여 있었다는 것이다 —
[02](./02-artwork-detail.md)와 [04](./04-artwork-edit.md)는 *"[데모 초기화]와 역할이 겹친다"*는 이유로
**삭제 버튼을 뺐다**고 적혀 있다.
**없는 기능을 근거로 다른 결정을 내린 상태**가 제일 나쁘다 — 근거가 사라지면 그 결정도 같이 무너진다.

그리고 이건 부가 기능이 아니다. 처음 여는 사람은 **되돌릴 수 없으면 아무것도 안 눌러본다.**
등록·편집·주문·상태 변경을 다 만들어놔도 구경만 하고 나간다.
**나머지 기능을 쓰이게 만드는 장치**다.

## 판단

### 🔑 "직접 만든 것 삭제"만으로는 부족하다

시드 작품의 설명을 고치면 그 행의 `origin`은 **`SEED` 그대로**다 — 삭제 대상이 아니다.
그러면 고쳐진 문장이 **영구히 남고**, 다음에 이 저장소를 여는 사람은 원래 문장을 볼 수 없다.

초기화는 **① 직접 만든 것 삭제 + ② 시드 재적용** 둘 다여야 한다.

**실제로 시험했다** — `seed-09-tadpole`의 말을 `이 문장은 초기화되면 사라져야 한다`로,
날짜를 `2026-12-25`로 고쳐두고 초기화했더니
`몸통은 안 그렸어. 옷 입고 있으니까 안 보이잖아.` / `2026-01-08`로 돌아왔다.

### 고아 데이터를 손으로 지우지 않는다

`Photo`·`Order`·`OrderEvent`가 전부 `onDelete: Cascade`로 매달려 있다.
**스키마가 이미 보장하는 것을 코드에 두 번 적으면 한쪽만 고쳤을 때 갈라진다.**
`Collection` 1건 + `Order` 2건 + `OrderEvent` 5건이 **책 하나를 지우는 것으로** 전부 사라졌다.

### 시드가 만든 것은 지우고 다시 넣지 않는다

전부 지우고 다시 넣는 편이 코드는 짧다. 그런데 **사진 바이트 1.7MB를 매번 다시 쓰게 되고**,
*"초기화하면 사진이 사라졌다가 돌아온다"*는 상태를 만들 이유가 없다.

### `confirm()` 대신 `<details>`

되돌릴 수 없는 버튼이라 한 번에 눌리면 안 된다. 그렇다고 대화상자를 쓰지 않았다 —
**무엇이 지워지고 무엇이 남는지 설명할 자리가 없다.**
펼치면 그 설명을 **읽고 나서** 누르게 된다. 표지 제목 고치기([07](./07-collection.md))와 같은 패턴이다.

### 홈 맨 아래에 조용히

처음 여는 사람에게는 필요하고 **주 사용자에게는 필요 없는** 기능이라,
찾으면 보이되 먼저 보이지는 않아야 한다.

### 의도적으로 넣지 않은 것

| 안 넣은 것 | 이유 |
|---|---|
| 개별 삭제 | 이 버튼 하나로 되돌아간다. 개별 삭제를 두면 *"이건 지워지고 저건 안 지워지는"* 규칙을 사용자가 외워야 한다 |
| 되돌리기(undo) | **초기화를 되돌리는 초기화는 설명할 수 없다** |
| 비밀번호·확인 문구 | 이 데이터는 **누구의 것도 아니다.** 지키는 비용이 얻는 것보다 크다 |
| 자동 초기화 | 심사자가 만들던 것이 보는 중에 사라진다 |

## AI를 어떻게 다뤘나

**채택**: `lib/seed-data.ts`의 배선을 그대로 썼다.
그 파일 머리말에 *"[데모 초기화]가 이 함수를 다시 부른다"*고 **미리 적어둔 대로** 동작했다 —
`prisma/seed.ts`에서 부수효과를 떼어낸 판단이 여기서 회수됐다.

**거부·수정 1 — `applySeed`를 트랜잭션 안에 넣으려 했다.**
안전해 보였지만 `applySeed`는 **이미지 파일 10개를 읽어 `upsert` 10번을 도는** 작업이라
트랜잭션 안에 두면 그 시간 내내 잠금을 잡는다.
그리고 둘의 성패를 묶을 이유가 없다 — 삭제가 끝났으면 재적용이 실패해도 다시 누르면 된다.

**거부·수정 2 — `revalidatePath`를 화면마다 적으려 했다.**
다 적으면 **화면을 하나 더 만들 때 여기를 고치는 걸 잊는다.**
`revalidatePath("/", "layout")` 하나로 바꿨다.
