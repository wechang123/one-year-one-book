# 06. 지금 깨져 있던 것 3건 — 빈 실패 화면 · 죽은 검사 · 프리렌더

> 이슈 #11 · `app/error.tsx` · `next.config.ts` · `app/artwork/new/`

세 건 다 **"동작한다고 적혀 있는데 실제로는 아닌"** 종류였다.

## ① 실패했을 때 화면이 아무 말도 안 했다

DB를 끄고 홈을 열어봤다. 응답 **5,334바이트가 전량 `script`·`link`**고
사용자 눈에 남는 글자는 `<title>` 하나였다. **빈 화면이 곧 실패 화면**이었다.

세 갈래가 전부 여기로 모인다 — DB 단절 · 서버 액션 예외 · **업로드 본문 한도 초과**.
마지막 것은 폼이 잡을 수 없다. **액션이 시작되지도 못하므로** `useActionState`에 오류가 안 온다.
그래서 ①과 ②는 **한 쌍**이다.

**판단**

- **문구가 사과가 아니라 범위 축소다.** 404와 같은 판단이다 —
  부모가 맡긴 것이 *"버려도 된다"*는 허락이라, 화면이 비면 첫 생각이 **"내 기록이 날아갔나"**다.
  그래서 먼저 하는 말이 `남기신 작품은 그대로 있습니다`다.
- **새 CSS는 정렬 한 줄뿐.** 빈 목록·404와 같은 `.blank`를 쓴다.

## ② 크기 검사가 도달할 수 없는 코드였다

`bodySizeLimit`과 `MAX_BYTES`가 **둘 다 8MiB**였다.
그런데 `bodySizeLimit`은 **파일이 아니라 요청 본문 전체**에 걸린다 —
multipart 경계, 필드 이름, 아이 말, 만든 날까지 포함한 크기다.

8MiB를 넘는 파일은 본문이 먼저 잘려 **액션이 시작조차 못 한다.**
`"사진이 너무 큽니다"`는 **절대 실행되지 않는 코드**였고, 화면의 `"8MB까지"`는 경계에서 거짓말을 했다.

진짜 JPEG 헤더(`ff d8 ff`)로 시작하는 **8,936,491B(8.52MiB)** 파일을 만들어 제출했다.

| `bodySizeLimit` | 결과 |
|---|---|
| `"8mb"` (수정 전) | 서버 한국어 문구 **0건** · 오류 경계로 떨어짐 → **죽은 코드 실증** |
| `"12mb"` (수정 후) | `사진이 너무 큽니다 (8.5MB). 8.0MB까지 올릴 수 있어요.` · 초점 이동 |

**수정 전 실행이 ①의 필요성도 같이 증명했다** — 그 경우가 오류 경계로 떨어졌고,
①이 없었으면 사용자는 빈 화면을 봤다.

**클라이언트 가드도 넣었다.** 역할이 다르다 —
서버는 **데이터를 지키고**, 클라이언트는 **시간을 지킨다.**
폰 회선으로 10MB를 다 올려보낸 뒤 거절당하는 건 서버가 옳게 답한 것이지만 사용자에겐 낭비다.

## ③ 등록 화면만 프리렌더되고 있었다

DB를 안 읽는 유일한 화면이라 Next가 정적으로 판단했고,
그 결과 **기본 날짜와 `max` 속성이 빌드한 날에 고정**된다.

빌드 출력으로 대조했다.

```
[force-dynamic 없이]        [넣고]
└ ○ /artwork/new            └ ƒ /artwork/new
  ○ (Static) prerendered      ƒ (Dynamic) server-rendered on demand
```

## AI를 어떻게 다뤘나

**🔴 거부·수정 — `reset()`만 부르는 표준 형태가 실제로는 복구를 못 했다.**

`error.tsx`의 표준 형태는 `onClick={reset}`이다. 그대로 넣고 **눌러봤다** —
DB를 껐다 켠 뒤 [다시 시도]를 눌렀는데 **오류 화면이 그대로 남고 카드가 0개**였다.

`reset()`은 *이미 받아둔 데이터로 경계 안쪽을 다시 그릴 뿐*이다.
여기서 실패한 건 서버 컴포넌트의 쿼리라, 서버에서 화면을 다시 받아오지 않으면 같은 실패가 반복된다.
`router.refresh()`를 앞에 붙이고 `useTransition`으로 묶었다.

> 🔑 **동작하지 않는 [다시 시도]는 없는 것보다 나쁘다.**
> 눌러본 사용자가 *"복구가 안 되는 상황"*이라고 잘못 배우게 된다.
> **표준 형태를 넣었다는 것과 그게 이 화면에서 동작한다는 것은 다른 이야기다.**

## 확인

|---|---|

| DB 복구 후 [다시 시도] | `다시 불러오는 중…` → **오류 화면 사라지고 카드 10개 · "작품 10점"** |

| `/artwork/new` 프리렌더 | `○ Static` → **`ƒ Dynamic`** |
| `npm run build` | exit 0 |
| `npm run lint` | 통과 |
