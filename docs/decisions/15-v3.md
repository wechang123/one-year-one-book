# v3 — 재질과 활자. 참고한 것과 안 가져온 것

> 참고: [typo.love](https://www.typo.love) — *"말하지 못한 말들의 인터랙티브 아카이브"*
> 요구: *"이런 걸 원한 거야. v3라 해도 돼. 기존에 있는 기능도 이런 스타일로 디벨롭해줘."*

---

## 0. 무엇을 보고 왔나

typo.love를 열어 첫 화면과 `[ INFO ]` 화면을 직접 봤다.

| 요소 | 관찰 |
|---|---|
| 표제 | 세리프, 소문자, 크게. `typo.love` |
| 읽는 글 | 타자기 고정폭, 넉넉한 줄간 |
| 라벨 | `[ INFO ]` `[ SUBMISSIONS CLOSED ]` — 대괄호 + 넓은 자간 + 아주 작게 |
| 배경 | 오프화이트 + **눈에 보이는 종이 그레인** |
| 크롬 | 네 귀퉁이의 마이크로 라벨뿐 |
| 색 | 배경은 무채색, **사물이 색을 가진다** |
| 재질 | 봉투 · 밀랍 · 종이 그림자 |

## 🔑 우리가 이미 가진 것부터 셌다

**"사물이 색을 가진다"와 종이 은유는 v1·v2에 이미 있었다** —
아이 그림이 화면에서 제일 화려하고(`⛔ 색은 여섯 개만`), 시드 이미지가 "책상 위 종이"를 그리고
(`scripts/seed-images.mjs`의 `sheet()`·`grain()`), 카드 그림자가 그 은유를 잇는다.

**없던 것은 활자와 바탕이다.** 그래서 v3는 화면을 갈아엎는 작업이 아니라
**이미 있던 은유를 활자와 재질까지 밀어 넣는 작업**이 됐다.

---

## 1. 이름은 명조, 읽는 글은 산세리프

### 문제

v1·v2는 **이름과 본문의 구별을 굵기와 크기로만** 했다.
`타임라인`(700, 32px)과 아이 말(400, 15px)이 **같은 활자**다.
그건 같은 목소리를 크게 낸 것이지 다른 목소리가 아니다.

### 갈림길

| 후보 | 판정 |
|---|---|
| 굵기·크기 대비를 더 키운다 | ❌ 이미 32px 대 15px다. 더 키우면 표제가 소리를 지른다 |
| 라틴만 세리프 | ❌ 우리 표제는 **전부 한글**이다. `2026년`의 숫자만 세리프면 그게 더 이상하다 |
| **한글 명조 한 벌** | ✅ 화면이 *"읽는 곳"*과 *"부르는 곳"*으로 갈린다 |

### 어느 명조인가 — 재고 골랐다

| | 원본 | 서브셋(KS X 1001) |
|---|---|---|
| **Gowun Batang** (OFL, 류양희) | 8,236KB | **200KB** |
| Nanum Myeongjo (OFL, 산돌) | 2,987KB | 327KB |

**작은 쪽이 마침 typo.love의 부드러운 세리프에 더 가까웠다.**
자르는 코드는 Pretendard와 같은 스크립트를 확장했다(`scripts/subset-font.mjs`).

🔑 **굵기가 하나(Regular)다.** 표제에만 쓰고 강조는 크기와 색이 하므로 Bold를 같이 실을 이유가 없다 —
실으면 200KB가 두 배가 된다. 그리고 **명조를 굵게 만들면 명조가 아니게 되기도 한다.**

### 대가

글꼴 합계가 **309 → 508KB**가 됐다. 숨기지 않는다.
둘 다 `display: swap`이고 한 번 받으면 캐시된다. 시드 이미지(364KB)와 같은 층위의 비용이다.

## 2. 대괄호 마이크로 라벨 — 규칙을 한 번 좁혔다

typo.love의 `[ INFO ]`를 가져오면서 **모든 메타 줄에 괄호를 씌웠다.** 그랬더니 화면에 이런 게 떴다:

```
[ 하늘의 기록 · 임신 14주 5일부터 만 7세 4개월까지 12점 ]
```

🔴 **`[ INFO ]`는 이름표지 문장이 아니다.** 문장을 괄호로 묶으면
그건 마이크로 라벨이 아니라 **그냥 괄호 친 문장**이다.

> 🔑 좁힌 규칙: **대괄호는 이름표에만.** 문장은 작은 크기와 자간까지만 가져간다.

| 괄호 O (이름표) | 괄호 X (문장) |
|---|---|
| `[ 한 해가 한 권 ]` · `[ 2026년 · 한 해가 한 권 ]` · `[ 주문번호 20260804-CFDU ]` | `하늘의 기록 · 임신 14주 5일부터…` · `지난 기록과 앞으로의 검진을 한 장에` |

괄호는 `::before`/`::after`로 넣는다. 마크업의 문장은 `한 해가 한 권`이고 괄호는 **생김새**다 —
글자로 박으면 스크린리더가 `대괄호 한 해가 한 권 대괄호`를 읽는다.

**한글에는 대문자가 없다.** 영문 마이크로 라벨은 대문자가 절반을 하는데 우리는 못 쓴다.
그 몫을 자간(`0.08em`)과 크기(12px)와 괄호가 나눠 진다.

## 3. 종이 그레인

바탕에 잡음을 아주 옅게(`opacity 0.038`) 깐다.
**시드 이미지가 이미 종이에 그레인을 굽고 있고 카드 그림자가 "책상 위"라고 말하는데,
바탕이 종이가 아니면 그 둘이 붕 뜬다.**

- ⛔ **그라데이션이 아니다.** `feTurbulence`가 만드는 것은 잡음이고,
  이 저장소가 금지한 것은 *"장식으로 쓰는 색의 번짐"*이다
- 🔑 **SVG를 데이터 URI로 인라인**한다 — 외부 호출 0, 파일 0개, 이미지 요청 0건

---

## 4. 크롬을 더 조용하게

사이드바의 현재 화면 표시가 **배경을 채운 알약**이었다.
typo.love는 크롬이 귀퉁이의 마이크로 라벨뿐이다.

우리는 **화면이 다섯이라 메뉴를 없앨 수 없다.** 대신 채운 면을 걷고 **왼쪽 선 하나**로 바꿨다.
**면은 시선을 끌고 선은 자리를 알린다.**

---

## 4-b. 🔴 여기까지가 스킨이었다 — 한 번 더 들었다

위의 넷(명조 · 대괄호 · 그레인 · 조용한 크롬)을 올리고 나서 받은 말:

> **"바뀐 게 글꼴밖에 없는데?"**

**맞는 말이었다.** 활자와 바탕을 갈아입혔지만 **배치는 v2 그대로**였다.
타임라인은 여전히 `점 16px · 썸네일 56px · 나머지 글`짜리 가로 줄이었다.

### 왜 스킨으로 끝났나

typo.love가 그렇게 보이는 이유를 **활자로 오해했다.** 다시 보면 진짜 이유는 이거다 —
**사물이 화면을 차지한다.** 봉투가 200~400px이고 나머지가 그 둘레로 물러난다.

우리 화면은 반대였다. **사진이 56px이고 그 옆 글자가 더 컸다.**
이 서비스가 받아두는 것이 사진인데 화면에서 사진이 가장 작으면,
그건 사진 목록이 아니라 **사진이 붙은 활동 로그**다.

### 고친 것

| | 전 | 후 |
|---|---|---|
| 사진 | 56px 썸네일 | **384×328 판** (원본 비율, `contain`) |
| 배치 | 가로 3칸 | 폰은 세로, 1000px↑ **사진 왼쪽 · 말 오른쪽** |
| 아이 말 | 15px | **18px**, 줄간 1.75 |
| 띠 표 | 15px 굵게 | **32px 명조** |
| 세로 축선 | 있음 | **지웠다** |

**축선을 지운 이유**: 항목이 작을 때 순서를 말해주던 장치였는데, **항목이 커지면 순서는 항목이 말한다.**
선은 그때부터 관리 화면의 표시가 된다.

### 🔴 그 과정에서 두 번 틀렸다

**① 세로로만 쌓았더니 화면이 텅 비었다.**
한 항목이 580px이 되고 오른쪽 900px이 통째로 비어서, 스크롤하다 보면
**화면에 아무것도 없는 구간**이 나왔다. 재보니 문서 높이 7,447px에 한 화면당 1.33항목.
**사물을 키운 것은 맞았고 키운 사물을 세로로만 쌓은 것이 틀렸다.** 넓은 화면에서 옆으로 폈다.

**② 사진이 전부 점으로 접혔다.**
틀의 비율 고정을 빼면서 `img`에 `width: auto`를 걸었는데,
**마크업의 `width`/`height` 속성이 잡아둔 자리를 CSS가 취소한다.**
`loading="lazy"`와 겹쳐서 화면에 **점 열둘**만 남았다.

> 🔑 이 저장소는 **v1에서 이미 같은 것을 배웠다** — `.card__frame`의
> *"사진이 도착하기 전에도 칸의 높이가 정해져 있어야 한다"*.
> 거기는 정사각으로 풀었고, 여기는 사진마다 다른 **원본 비율**을 틀에 넘겨서 푼다.
> **배운 것을 다른 화면에서 다시 밟았다.**

## 🔴 5. 안 가져온 것 셋

| | 왜 |
|---|---|
| **3D orbit 캔버스** | WebGL 의존성이 생긴다. 그보다 **우리 콘텐츠는 봉투가 아니라 사진**이다 — typo.love의 봉투는 *닫혀 있는 것*이라 공중에 떠 있어도 되지만, **사진은 보라고 있는 것**이다. 띄우면 안 보인다 |
| **배경 음악** | 이 앱은 소리를 내지 않는다. **손에 실물이 들려 있는 30초**에 여는 앱이고, 그 30초에 음악이 시작되면 방해다 |
| **크롬 완전 제거** | typo.love는 **화면이 하나**다. 우리는 다섯이고 그 사이를 오간다. 귀퉁이 라벨만 남기면 이동이 사라진다 |

> 🔑 셋 다 *"멋있는데 우리 것이 아니어서"*가 아니다. **콘텐츠가 다르고, 화면 수가 다르고,
> 여는 순간이 다르다.** 참고한 화면을 그대로 베끼면 그 세 가지가 안 맞는 자리에서 깨진다.
