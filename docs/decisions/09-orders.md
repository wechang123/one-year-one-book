# 09. 주문 목록·상세 — 상태를 사용자 말로

> 이슈 #8 · PR #15 · `app/orders/` · `lib/order-status.ts`

## 왜

주문을 저장할 수는 있는데 **볼 곳이 없었다.**

## 판단

### 목록과 상세가 서로 다른 질문에 답한다

| | 답하는 질문 | 어떻게 읽나 |
|---|---|---|
| **목록** | 지금 어느 상태인가 | **조인 없이 `Order.status`만** |
| **상세** | **언제부터 그 상태였나** | `OrderEvent`를 **시간순**으로 |

`OrderEvent`에 이력이 다 있는데도 `Order.status`를 따로 둔 이유가 이것이다.
이력만 있으면 목록 10건마다 최신 이벤트를 찾아야 한다.
**이 화면이 가벼운 것은 우연이 아니라 스키마가 그렇게 생긴 결과다.**

상세가 다른 질문에 답하는 이유 — *"인쇄 중이라는데 어제부터인가 방금부터인가"*가
**기다릴지 전화할지를 가른다.** 현재 상태만 덮어썼으면 그 답이 사라진다.

### 상태 문구를 한 곳에 모았다 (`lib/order-status.ts`)

상태는 **세 화면**에 나온다 — 목록 · 상세 · 상태 변경 버튼.
화면마다 적으면 한 곳을 고칠 때 나머지가 남고,
*목록에서는 "인쇄 중"인데 상세에서는 "제작 중"인 주문*이 생긴다.
**사용자는 그게 같은 상태인지 다른 상태인지 알 방법이 없다.**

**`RECEIVED`·`PRINTING`·`SHIPPING`을 화면에 내보내지 않는다.**
그건 DB의 값이지 사람에게 하는 말이 아니다. 목록 HTML을 `grep`해 **영문 상태 0건**을 확인했다.

**라벨만으로는 부족해서 한 줄 설명을 같이 뒀다.**
`접수됨`만으로는 *"그래서 나는 뭘 기다리면 되나"*에 답이 안 된다.

**남은 단계를 흐리게 같이 보여준다.** 끝이 어디인지 모르면 기다리는 시간이 더 길게 느껴진다.
지나온 단계는 취소선이 아니라 옅은 채움이다 — **취소선은 "무효"로 읽힌다.**

### 주문 0건일 때 무엇을 말할지 먼저 정했다

*"주문이 없습니다"*로 끝내면 여기서 할 일이 없다.
이 서비스에서 주문이 없다는 건 **아직 책을 안 묶었거나 묶고 주문을 안 한 것**이라
**앞 단계로 돌려보낸다.** 같은 이유로 **홈의 주문 링크는 0건이면 안 나온다.**

### 주소창에 `orderNo`를 쓴다

**전화로 불러준 번호를 그대로 주소창에 넣어볼 수 있다.**
형식이 안 맞으면 DB까지 가지 않는다.

### 의도적으로 넣지 않은 것

| 안 넣은 것 | 이유 |
|---|---|
| 배송 조회 링크 | 배송사 연동이 없다. 누를 수 없는 링크를 두면 **연동된 것처럼 보인다** |
| 예상 도착일 | 제작 사양이 없어 근거가 없다 |
| 주문 검색·필터 | 주문이 한 자릿수다 |
| 색만으로 상태 구분 | 배지의 **글자가 상태 이름을 그대로 말한다.** 색을 못 봐도 정보가 남는다 |

## AI를 어떻게 다뤘나

**거부·수정 1 — `formatMadeOn`을 `createdAt`에도 쓸 뻔했다.**
같은 파일의 함수라 자연스러워 보였는데, 그건 **`madeOn` 전용으로 UTC에 고정**해둔 것이다
(`@db.Date`라 시각이 없어서). 진짜 시각에 쓰면 한국 사용자에게 9시간 전으로 보이고
**자정 근처에서는 날짜가 하루 밀린다.**
`Asia/Seoul`을 **명시**한 포맷터를 따로 만들었다 — 컨테이너 `TZ`에 기대면 다른 환경에서 조용히 달라진다.

**거부·수정 2 — 시각이 `2026년 8월 3일 PM 5:54`로 나왔다.**
한글 날짜에 **영문 오전/오후**가 섞였다. `ko-KR`인데도 그런 건 실행 환경의 ICU 로케일 데이터 때문이다.
취향 문제로 넘길 뻔했는데, **실행 환경마다 다른 글자가 나온다는 게 진짜 문제**다.
`hour12: false`로 고정해 그 변수를 없앴다.

## 확인

| 확인 | 결과 |
|---|---|
| `/orders` | `주문 5건` · **1440px에서 4열** |
| 목록 한 건 | 번호 / `접수됨` / 책 제목·연도 / `고모 님께 · 2026년 8월 3일 주문 · 1/3단계` |
| **영문 상태 노출** | HTML grep **0건** |
| 상세 | 단계 `접수됨(현재) · 인쇄 중 · 배송 중` + 한 줄 설명 |
| 이력 | `2026년 8월 3일 17:54 주문이 접수되었습니다` (24시간제) |
| **주문 0건** | `아직 넣으신 주문이 없어요.` + [책 묶으러 가기] · **홈 링크도 사라짐** |
| `/orders/NOPE` · `/orders/20260803-0000` | HTTP **404** (금지 글자라 DB까지 안 간다) |
