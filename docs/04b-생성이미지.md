## 0-b. 🔴 왜 다시 폈나

전제가 바뀌었다. 이제 이 서비스는 **초음파 사진부터 상장까지** 받는다.
§0에서 접은 세 가지가 그 전제 아래에서 어떻게 되는지 하나씩 본다.

| 접었던 이유 | 지금 |
|---|---|
| **실물이 아니다** | ✅ **여전히 유효하다. 그래서 방법을 바꿨다.** 아래 참조 |
| **화풍 통제가 함정이다** | 🔄 **뒤집혔다.** 그 말은 *한 해*를 볼 때 맞았다. 지금은 **8년**을 본다 — 8년이면 화풍이 변해야 하고, **변화가 보이려면 같은 손이어야 한다.** 서로 다른 여덟 아이의 그림을 모아두면 이 서비스의 새 주장(한 아이의 시간 전체)을 데모가 부정한다 |
| **문장이 먼저면 순서가 거꾸로다** | ✅ **여전히 유효하다.** 그래서 이번에도 **그림을 먼저 그리고 말을 나중에 썼다.** §2의 프롬프트는 그림을 정의할 뿐 문장을 담지 않는다 |

### 그리고 CC0로는 확보할 수 없는 것이 생겼다

**초음파 사진과 상장이다.**
실제 초음파 출력지에는 **산모 이름·병원명·판독 정보**가 찍혀 있고, 상장에는 **아이 실명과 학교명**이 있다.
공개 저장소에 올릴 수 있는 CC0 초음파·상장을 구하는 것은 사실상 불가능하고,
**구해지더라도 그건 실존하는 누군가의 임신 기록이다.**
이 저장소는 *"제3자 실명을 쓰지 않는다"*를 규칙으로 갖고 있는데, 그 규칙과 정면으로 부딪힌다.

> 🔑 **판정: 확장된 범위에서는 생성이 유일하게 안전한 경로다.**
> 안 골라서 안 쓴 것이 아니라 **쓸 수 있는 것이 이것뿐**이다.

### "실물이 아니다"는 그대로 남는다 — 그래서 촬영을 흉내 냈다

§0의 첫 번째 이유는 지금도 맞다. 화면 안에서 태어난 반듯한 사각형 이미지는
**버릴 실물이 없어 보인다.** 그래서 생성 방식 자체를 그 문제에 맞췄다 —
**종이를 기울여 놓고 그림자를 깔고 종이 결을 얹는다.** `scripts/seed-images.mjs`의 `sheet()`가 그 일만 한다.
완전히 속이지는 못한다. **속이려는 것도 아니다** — 시드는 소품이고, 소품이라는 사실을 문서가 밝힌다.

## 0-c. 🔴 그런데 이미지 모델로 만들지 않았다 — 코드로 그렸다

**이건 정확히 적어야 한다.** 아래 §1~§2의 프롬프트는 *이미지 모델에 넣는 형태*로 쓰여 있지만,
**실제로 픽셀을 만든 것은 확산 모델이 아니라 `scripts/seed-images.mjs`다** —
AI가 SVG 도형을 직접 그리고 `sharp`가 래스터화했다.

**갈림길: 이미지 모델 / 코드 생성 → 코드.**

| | |
|---|---|
| 🔑 **재현성** | 확산 모델은 같은 프롬프트로 같은 그림을 다시 주지 않는다. 그러면 **저장소가 자기 시드를 다시 만들 수 없다.** 여기서는 난수까지 고정 시드라 몇 번을 돌려도 같은 바이트가 나온다 |
| **저작권** | 학습 데이터 논란이 아예 걸리지 않는다. 좌표와 색뿐이다 |
| **글자** | 이미지 모델은 한글을 거의 못 쓴다(§1이 그래서 `no text`를 걸었다). **상장은 글자가 본체다.** 코드로 그리면 그냥 된다 |
| **대가** | 사진 같은 질감이 안 나온다. 종이 결·기울기·그림자로 흉내 낼 뿐이고, **자세히 보면 생성물인 게 보인다.** 받아들였다 — 소품이기 때문이다 |

프롬프트를 지우지 않고 남기는 이유: **무엇을 그리려 했는지가 곧 생성 규칙**이고,
코드가 하는 일이 그 규칙을 따르는 것이다. 아래 §1의 공통 규칙은 코드에도 그대로 들어가 있다.

## 0-d. 사람과 이름에 대한 규칙 — 유지하고 하나 더 걸었다

| | |
|---|---|
| **아이 얼굴 금지** | 🔒 **유지.** 생성이라도 실제 아이 사진처럼 보이는 얼굴은 만들지 않는다. 그림 속 얼굴은 **아이가 그린 낙서**이므로 해당 없다 |
| **실명처럼 보이는 텍스트 금지** | 🆕 **추가.** 상장과 초음파에 이름이 들어가는데, **생성물이라도 실명처럼 보이면 실명처럼 읽힌다.** 그래서 저장소가 이미 *가상*이라고 밝힌 시드 아이 이름 **`하늘`** 하나만 쓴다 |
| **기관명 금지** | 🆕 병원명·학교명·유치원명을 넣지 않는다. **실재하는 이름과 겹칠 수 있다.** 상장에는 발급 기관 줄이 아예 없고, 초음파에는 날짜와 주수만 있다 |

## 0. ~~왜 접었나~~ — 접었던 판단 (§0-b에서 다시 폈다)

| 접은 이유 | |
|---|---|
| **실물이 아니다** | 이 서비스의 전제가 *"실물이 쌓여서 버려야 한다"*이다. 생성 이미지는 **버릴 실물이 없다.** 데모가 제품의 전제를 부정한다 |
| **화풍 통제가 목적이었는데, 그게 오히려 함정이었다** | *"12장이 한 아이의 화풍으로 보이게"*가 이 경로의 핵심 장점이었다. 그런데 진짜 아이 그림은 **한 해 안에서도 화풍이 튄다.** 고르게 만드는 건 진짜처럼 보이는 게 아니라 그 반대다 |
| **문장에 맞는 그림을 만들려던 것 자체가 순서가 거꾸로였다** | ③번 근거가 *"문장에 정확히 맞는 그림을 찾을 수 없다"*였다. 실제로는 **그림이 먼저고 말이 나중**이다(`worklog` 10:43). 이 문서는 뒤집힌 순서 위에 세워져 있었다 |

**지우지 않는 이유** — 검토했다가 접은 기록은 그 자체가 판단의 증거다.
무엇을 안 골랐는지가 없으면, 고른 것이 유일한 선택지였는지 우연이었는지 알 수 없다.

> 🔴 **위 세 줄 중 두 번째는 뒤집혔고 나머지 둘은 살아 있다.** 어느 것이 어떻게 됐는지는 §0-b의 표에 있다.
> 표를 지우지 않는 이유가 여기 있다 — **뒤집힌 이유와 살아남은 이유를 같이 봐야** 이번 판단이 설명된다.

## 1. 공통 규칙 — 모든 프롬프트에 붙인다

12장이 **같은 아이가 같은 화구로 그린 것**처럼 보이려면 아래를 고정한다.

```
STYLE (append to every prompt):
a drawing made by a 5-year-old child, crayon and colored pencil on white paper,
wobbly uneven lines, colors going outside the lines, simple flat shapes,
no perspective, no shading, disproportionate figures,
photographed flat from directly above on a plain white desk, soft even daylight,
slight paper texture and a small crease, no frame, no border, no signature,
NOT professional, NOT polished, NOT detailed, NOT digital art, NOT vector
```

### 🔴 반드시 지킬 것

| | |
|---|---|
| **사람 얼굴 금지** | 실제 아이 사진처럼 보이는 것 금지. **그림 속 사람은 졸라맨 수준의 낙서**여야 한다 |
| **너무 잘 그리면 실패** | 이미지 모델은 자꾸 예쁘게 만든다. `NOT professional` 계열 부정어를 반드시 유지 |
| **글자 금지** | AI가 만든 한글은 대부분 깨진다. `no text, no letters, no numbers` 추가 |
| **정면 촬영** | 12장이 같은 각도여야 한 사람의 아카이브로 보인다 |

### 성장 표현 — 시기별로 이 문구를 섞는다

| 시기 | 추가 문구 |
|---|---|
| 3~6월 (더 어림) | `very simple, only 2-3 elements, huge empty white space, thick clumsy strokes` |
| 7~10월 (중간) | `a few more elements, still very simple` |
| 11~2월 (조금 자람) | `more elements and small details, still clearly childlike` |

## 3. 생성 후 처리

```bash
# 1) 받은 파일을 01.jpg ~ 12.jpg로 이름 통일
# 2) 리사이즈 — 저장소 용량을 위해 긴 변 1200px, 품질 82
cd public/seed
for f in *.jpg; do sips -Z 1200 "$f" --setProperty formatOptions 82 >/dev/null; done
ls -lh    # 한 장당 200~400KB, 12장 합계 5MB 이내 목표
```

| 항목 | 기준 |
|---|---|
| 크기 | 긴 변 1200px |
| 형식 | JPG (PNG는 용량이 3~4배) |
| 합계 | **5MB 이내** — 저장소에 커밋되고 Docker 이미지에도 들어간다 |
| 위치 | `public/seed/` — 커밋한다. `next start`가 부팅 시 스캔하므로 클린 클론에서 살아남는다 |

```markdown
더미 데이터의 그림 12장은 **생성형 AI로 만들었습니다.**

- 실제 아이의 작품을 쓰지 않은 이유: 공개 저장소이고, 아동의 창작물과 초상은
  본인·보호자 동의 없이 배포할 수 없다고 판단했습니다.
- 무료 스톡 이미지를 쓰지 않은 이유: 12장이 **한 아이의 그림처럼 보여야** 하고,
  각 그림이 **아이의 설명과 정확히 맞아야** 하는데 스톡으로는 통제할 수 없었습니다.
- 사용 도구: (도구명·버전)
- 프롬프트 설계 기록: (이 문서)
```

> **이 문단 자체가 산출물이다.** 제출 요건에 *의도적으로 넣지 않은 것과 그 이유*를 쓰는 항목이 있고,
> 여기서는 *"실제 아이 작품을 쓰지 않은 판단"*이 그 답이 된다.

## 5. 🔴 실제로 만든 것 — 12점

위 §2는 **12장 전부 그림**이던 시절의 계획이다. 지금은 종류가 넷이다.
아래가 `scripts/seed-images.mjs`가 실제로 그리는 것이고, **말은 그림을 그린 뒤에 썼다.**

### 공통 규칙 (코드의 `sheet()`가 하는 일)

```
EVERY IMAGE:
  a physical sheet photographed from directly above on a plain grey desk,
  the sheet rotated by about 1 degree (never perfectly square to the frame),
  a soft drop shadow under the sheet,
  fine paper grain over the whole image,
  no border decoration, no watermark, no signature
```

> 🔑 **기울기와 그림자가 이 규칙의 전부다.** §0의 *"실물이 아니다"*가 지금도 유효해서
> 남은 대응이 그것뿐이다 — **찍은 것처럼 보여야 버릴 실물이 있는 것으로 읽힌다.**

```
EVERY DRAWING (05, 06, 07, 09, 10, 12):
  crayon on drawing paper, wobbly uneven lines drawn two or three times over,
  flat colors, no perspective, no shading, disproportionate figures,
  NOT professional, NOT polished, NOT detailed
```

**말 열 개는 전부 사진만으로는 알 수 없는 것을 담는다.**
아홉은 사진에 아예 없는 사실이고(심장 소리 · 퇴원복 · 반 전체가 받은 상장 · 그리다 만 이유),
하나(`10-self-b`의 *"이번엔"*)는 **앞 장과 나란히 놓여야 읽힌다.**
자연 표본이 아니라 **골라 쓴 것**이다 — 이 서비스가 지키겠다는 것이 *"안 물어보면 사라지는 말"*이라,
시드가 그걸 한 번도 안 보여주면 주장에 증거가 없다.

두 점(`06-scribble` · `11-paper-fold`)은 **비워뒀다.**
`11`이 최신 두 번째라 격자 첫 줄에 빈 말이 뜬다 — 숨기지 않으려면 잘 보이는 자리여야 한다.
