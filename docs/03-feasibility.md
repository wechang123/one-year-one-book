## 1. 경제 — 🟡 조건부 가능

**판정**: 아카이브 자체는 돈이 안 되지만, **아카이브 + 인쇄** 구조는 검증됐다.

**근거**
- **인쇄를 붙인 곳만 살아남았다.** Artkive·Plum Print·Artsonia(25년차)는 전부 현역. 반면 저장만 하는 Keepy는 2020-10 이후 업데이트 없고 공식 도메인 SSL 인증서까지 만료됐다(직접 확인).
- **학부모가 실제로 돈을 낸다.** Artsonia 자사 발표 기준 학교 기부 누적 $15M, 기부율은 굿즈 매출의 20%. 객단가는 Artkive $75~$740, Plum Print $175~.
- → **"아카이브는 제품이 아니라 인쇄의 전처리 공정"**이 이 카테고리의 반복 검증된 결론이다.

**🔴 이 조사가 설계를 실제로 바꾼 것 2건**

| 발견 | 바뀐 것 |
|---|---|
| **리틀피카소가 이미 "아이 목소리 기록"을 한다** (앱 설명 명시) | 차별점을 *"아이의 말을 남긴다"*에서 **"버릴 수 있게 만든다"**로 옮겼다. 말 기록은 선점됐고, **완결 동선(기록 → 확인 → 폐기 승인 → 한 권)**은 비어 있다 |
| **키즈노트가 85,000개 기관 채널을 갖고 있다** (자사 발표) | **B2C 정면승부를 배제**했다. 이 서비스는 "또 하나의 육아 앱"이 아니라 인쇄사가 이미 가진 기관 채널에 얹는 **연 1회 리텐션 장치**로 설명될 때 성립한다 |

**성립 조건 4가지** — ① 수익은 100% 인쇄 전환에 건다(구독 과금 금지) ② 차별점은 "말 기록"이 아니라 "버릴 수 있게 하는 완결 동선" ③ B2C 단독 진입 금지, 기관 채널 전제 ④ **감소하는 아동 수를 객단가로 상쇄**한다(유치원 원아 3.4%↓·초등 6.0%↓·어린이집 7.6%↓, 2025 교육기본통계 / 보육통계)

**물량 패턴**: 등록은 1년 내내 산발(인쇄 부하 0), **주문만 연말·학년말에 집중.** 인쇄사에겐 성수기에 얹히는 고단가 SKU다. 반대로 **비수기 가동률 개선 효과는 없다 — 이건 정직하게 인정한다.**

## 2. 기술 — 🟢 가능

**판정**: 사전에 실측해 두 개의 함정을 확정적으로 피했다.

| 실측한 것 | 결과 | 반영 |
|---|---|---|
| **`public/`에 업로드 파일을 쓰면?** | `next start`는 **부팅 시점에 스캔**한다. 실행 중 쓴 파일은 재시작 전까지 **404**. 볼륨을 붙여도 안 고쳐진다 | **업로드는 DB `Bytes` + route handler로 서빙.** 커밋된 시드 이미지는 부팅 때 이미 있으므로 정상 |
| **Server Action 기본 본문 크기** | **1MB.** 폰 사진은 2~5MB → **오류 없이 조용히 실패한다** | `next.config.ts`에 `serverActions.bodySizeLimit` 적용. 🔴 이 값은 **앱이 받는 사진 한도보다 커야 한다** — 같게 두면 한도 초과 파일이 본문 단계에서 잘려 앱의 안내가 도달할 수 없는 코드가 된다(조사 당시엔 이 함정을 몰랐고, 실제로 그 상태로 만들었다가 나중에 재현해서 고쳤다) |

**스택 확정** — Next 16.2.12 / React 19.2.8 / Prisma 7.9.1 + `@prisma/adapter-pg` / PostgreSQL 18 / TypeScript 6.0.3.

> Prisma 7부터 **`datasource` 블록에 `url`을 둘 수 없다.** 연결 문자열은 `prisma.config.ts`가, 실제 연결은 드라이버 어댑터가 맡는다. (이걸 어겨서 8분을 썼다 — `worklog` 10:14)

**선정 기준 — 라이선스 위에 두 개를 더 걸었다**

### 3-2. 오픈소스

**판정**: **이 저장소를 공개하는 것은 "재배포"가 아니다.** 그래서 실질 의무가 거의 없다.

`package.json`에 이름을 적는 것은 패키지를 복제·배포하는 게 아니다. 저장소를 여는 사람이 `npm install`로 각자 원본에서 받는다. MIT·Apache·LGPL의 고지 의무는 전부 **배포가 트리거**다.

**의무가 발생하는 순간은 딱 셋** — ① `node_modules/` 커밋 ② 빌드된 Docker 이미지를 레지스트리에 push ③ 폰트 등 파일 자체를 커밋.
→ **`.gitignore`에 `node_modules/`를 넣고 이미지를 push하지 않으면 법적 부담의 90%가 발생조차 하지 않는다.** 요건인 *"`docker compose up`으로 로컬 빌드"*가 마침 이 안전 경로와 일치한다.

**🔑 `package-lock.json`을 직접 파싱한 실측** (조사 문서의 "latest 버전" 가정과 다르므로 **이 값이 정본**)

| 확인 | 값 |
|---|---|
| production 의존성 | **207개. GPL·AGPL·SSPL·UNLICENSED 0건** |
| `sharp@0.34.5` | **직접 의존성이 아니라 `next`의 `optionalDependencies`** — 뺄 수 없다 |
| `@img/sharp-libvips-*@1.2.4` | **10개가 LGPL-3.0-or-later**로 이미 production에 존재 (조사 문서는 1.3.2로 추정했다) |
| 조사 문서에 없던 3건 | `elkjs` **EPL-2.0** · `seq-queue` **라이선스 필드 없음** · `caniuse-lite` CC-BY-4.0 |
| `@prisma/studio-core@0.33.0` | Apache-2.0 정상 (2025-12 UNLICENSED 사고 미해당) |
| Tailwind·UI 라이브러리 | **현재 미설치** → 조사 문서의 Tailwind 권고는 "도입하지 않는다"로 반영 |

**하지 않기로 한 것**
- **ExifTool 계열 도입 금지.** 래퍼는 MIT지만 번들된 본체는 Artistic-1.0-Perl 또는 **GPL 듀얼**이고, `license-checker`류는 `package.json`만 읽어서 **"MIT"라고 잘못 보고한다.** 게다가 **제품 설계상으로도 필요 없다** — *아이가 만든 날* ≠ *사진 찍은 날*이라 **만든 날은 부모가 직접 입력하는 값**이다.
- shadcn/ui 코드 복사(복사 순간 내가 재배포하는 것이 된다) · 상용 폰트 커밋 · Tailwind Plus.

**제출 전에 할 것** — `THIRD-PARTY-NOTICES.md`에 **libvips가 LGPL-3.0-or-later라는 고지 1줄**, `LICENSE`(MIT), 그리고 아래 1회 실행.

```bash
npx license-checker-rseidelsohn --production \
  --failOn "GPL-2.0;GPL-3.0;AGPL-1.0;AGPL-3.0;SSPL-1.0;UNLICENSED"
```
